# AI 补充内容 · 期望行为规格（0.3.27 目标）

> 用途：源码级审计与浏览器实测的对照基准。凡与本文不符即为 bug。
> 入口：学习页「更多」→「AI 补内容（当前词/当前 c）」；设置页「AI 扩充（可选）」。

## 1. 配置与连通性

- 服务商：DeepSeek（默认）/ OpenAI 兼容；baseURL、模型、JSON 模式可配置。
- API Key：仅本机保存；页面只显示掩码（`sk-…xxxx`）；不得出现在导出/日志/console。
- 「测试连接」：发极小请求；成功显示「连接成功」；失败显示**底层原因**（HTTP 状态 + 响应体摘要），不得只显示「超时」。
- Key 存储方式：persistent（DB）/ session（刷新丢失）。
- 单次运行费用上限（默认 3 元）、全量预算（默认 40 元）。

## 2. 范围（scope）

- 今日要学、当前词库、当前词、指定含义、选择词库、自定义选词。
- 任意 scope 变化后：目标数、费用预估、旧错误/旧进度摘要必须**立即重算/清空**。
- 指定含义：列出当前词全部 c（编号、词性、中文），可多选；未勾选时目标数为 0 并提示「请先勾选要生成的含义」。
- 自定义选词：未选词库/未搜索时显示词库选择器或「请先选择词库/搜索」，不得空白 0/0。
- 自定义选词最多 500；选择变化即刷新目标数。

## 3. 类型（kind）与模式（mode）

- 类型多选：例句 examples、词组 phrases、助记 mnemonics、本义/引申链 semantics。
- 模式按类型：
  - examples / phrases / mnemonics：`仅缺失`（默认）/ `追加更多` / `覆盖`
  - semantics：`仅缺失`（默认）/ `替换该词本义`
- 目标计算：
  - 仅缺失：排除该词该类已有内容 + 已拒绝 + pending 草稿。
  - 追加/覆盖：忽略已有内容（仍排除已拒绝）。
  - semantics 仅缺失：只对**≥2 个含义**的词生成；单含义词跳过并在**确实全部单含义**时才显示提示。
  - 目标为 0：立即显示「没有可生成的词（已有/被排除）」，开始生成禁用；不得创建草稿。
- 模式/类型变化后：目标数、费用、旧 summary/error 必须同步刷新。


### 3.1 助记（mnemonics）质量要求（用户 2026-11-12 确认）

助记的目标是**帮助记住「单词 w → 具体含义 c」的映射**，不是只解释词根。

- 每条助记必须同时锚定：**单词拼写/发音/构词** + **该 c 的中文含义**；读者看完能由 w 想起 c。
- 允许形式（可混合，优先贴合该词）：
  1. 词根/构词拆解 + 一句话桥接到中文含义（例：`ad(向)+dress(引导) → 把话引向某人 → 致辞`）
  2. 谐音/近音联想（需自然，不硬凑）
  3. 形象/场景故事（把拼写片段与含义场景绑定）
  4. 对比/辨析（与易混词或同词其他 c 对比）
- 禁止：只写词源/词根解释而没有「→ 中文含义」的桥接；只重复中文释义；与目标 c 无关的通用助记。
- 多含义词：助记按 c 生成（w-c 级），展示在对应 c 行；不得只给单词级一条。
- 长度：1–2 句、≤60 字；中文为主，可含英文词根/单词。
- API 生成时 prompt 需包含目标 c 的中文与词性；审核框逐条显示 c。

## 4. 生成

- 开始生成：显示「正在生成 X / N · 已用 ¥」；控件禁用；取消按钮可用。
- 超时：60s 硬超时，提示错误码（如 AI_TIMEOUT），复位 loading，不无限转圈。
- 错误：401/402/429/网络/服务器错误给可读文案 + 可重试；失败批次不影响已成功批次。
- 取消：保留已生成条目（草稿），提示「已取消，草稿已保存」；不得清空已有内容。
- 生成中禁止再次点击开始生成。

## 5. 草稿（draft）

- 开始生成即创建 draft（记录 scope/kind/offset/seenKeys/总数），每批持久化，UI 显示「已生成 X / 总 Y（草稿已保存）」。
- 关闭面板再打开：若有未完成 draft → 显示「继续上次生成（X/Y）」/「放弃草稿」；继续时跳过已有条目；不得重新生成已有项。
- **审核并应用成功 → 立即清除 draft**；重开面板不得再出现继续/放弃横幅。
- 取消/超时/失败：保留已有 draft；仅 0 条目时可清空。
- 放弃草稿：二次确认；确认后删除草稿，不删除已应用内容。
- 已有未完成草稿时点「开始生成」：必须提示「请先继续或放弃草稿」，**禁止**静默新建、禁止清空旧草稿。
- 草稿不得出现在设置→内容包列表（不得作为 pack 行显示 0/0）。

## 6. 审核与应用

- 审核框：逐条 ✓/❌、全选/全不选、保存已选；拒绝项记录，之后 default 排除。
- 覆盖/替换模式：审核框明示「将替换」（旧内容会被替换）。
- 应用成功：注解面立即显示新例句/词组/助记/本义链；列表计数更新。
- **替换本义 P0 不变量**：应用后 Word 的 coreSenses 与 meaningMap **必须非空且为新内容**；注解面显示本义 1..n、词源、链；失败必须回滚保留旧内容，绝不出现空白本义区。
- 反复应用幂等：不产生重复例句/词组/助记；不产生空的 0/0 pack。
- 应用不得改动学习进度（记忆状态、下次复习）。

## 7. UI 状态

- 面板打开时底部/顶部不得出现幽灵横幅（草稿条穿层）。
- 旧错误/旧「完成 X/失败 Y」在选项变化或重开面板后清空。
- 开始生成在目标 0 或生成中禁用；取消在生成中可用。
- 长文本换行、深色/浅色可读；不被底部三键遮挡。
- 空草稿自动清理；保存后无残留。

## 8. 数据/测试不变量

- 每次 apply 后：pack items 与 Word 内容一致；effective content 取最新；旧 applied 不残留（替换场景）。
- 超时/失败/取消后数据不变（除已完成批次持久化的草稿）。
- 多次重复同一操作不产生重复 pack/重复内容。
