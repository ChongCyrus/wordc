# 2026-11-14 功能与修复清单（0.3.35 目标）

## 功能

### F1 w-c 页信息增强
- 在记忆 w-c 页展示**当前 c** 的：
  - 例句（英文 + 中文翻译，最多 3 条；无则不渲染）
  - 助记（绑定当前 c 的助记；无则不渲染）
  - 不熟悉度：条形 + 百分比（复用 FamiliarityBar 视觉）
  - 排名：该 c 在本 w 各 c 中的不熟悉度排名（如「第 2 / 5 不熟悉」），并列按稳定顺序
- 不破坏整屏点击 +1；信息区点击不触发 +1（stopPropagation）或整页仍 +1 但需明确；默认信息区不误触。

### F2 「加权记忆」按钮
- 注释面 ActionBar：在「记忆」旁新增「加权记忆」（并排，次级样式）。
- 流程与普通记忆一致（同一 w-c 页、同一配置/词组/字号/链），区别：
  - 每个 c 的总出现次数 = `clamp(round(baseRepeats × weight(unfamiliarity)), min, max)`；
  - 不熟悉度越高 → 次数越大；weight 可用线性：`1 + k × familiarity`（k 可配）或简单分档；提供设置：
    - 「加权记忆最少次数」min（1–10）
    - 「加权记忆最多次数」max（1–20，≥min）
    - 可选「加权强度」k（0–2，默认 1）
  - 普通「记忆」仍固定 `memory.totalRepeats`。
- 计数、点阵、完成判定按加权 total；完成该 c 后与普通记忆相同的推进逻辑（进入下一 c / 回注释面）。
- 设置页「记忆设置」增加上述配置；默认值不改变现有普通记忆行为（默认 min=1,max=10,k=1 仅影响加权按钮）。
- 文档 UI-STUDY / FEATURES 更新。

### F3 首页每日学习效率
- 首页 KPI 区域附近显示：
  - 平均记住一个单词所花时间（秒/词，今日）
  - 推算预计还需多久学完今日单词（分钟）
- 计算：记录学习会话活跃时间（进入学习→评分/离开的累计），今日已学词数；平均 = 活跃时长 / 已学词数；预计 = 平均 × 今日剩余（待复习+待新学，含 backlog？按今日任务剩余词数）。
- 无数据（0 词）显示「—」；不改变原有 3 KPI。
- 首页布局不挤压；小屏可换行。

### F4 白板面显示各 c 例句与词性
- 白板面（BoardStage）在单词下方展示每个 c 的：
  - 词性（如 n. / vt.）
  - 该 c 的英文例句（有则显示；无则该 c 只显示词性？）
- 不显示中文翻译（保持白板面回忆性质）；截断/最多条数可配置或沿用白板例句数量。
- 不得把答案（中文）泄露到白板面。

### F5 我的页使用说明
- 「我的」增加「使用说明」入口/区块。
- 包含推荐主流程：**记忆 → 回忆 → 标记不认识的 → 加权记忆 → 回忆 → 标记不认识的 → 加权记忆 …** 直至所有（主要）含义映射都能回忆。
- 说明各页面用途（白板/注释/w-c/三键/加权记忆/今日单词/统计），可折叠。

## 修复

### B1 助记被截断
- 注解面/审核框/w-c 助记文本完整显示（自动换行，不 line-clamp/不省略）；长文本不溢出。

### B2 每次 AI 补内容都新增一个内容包
- 同一 deck 的 AI 生成内容应合并到**一个** AI 内容包（或复用已有 AI 包追加 items），不再每次生成新建 1/1 包。
- 已存在的重复 AI 包提供「清理/合并」；内容包列表不再出现大量 1/1 重复包。

### B3 另一台手机内容包应用不完整（重应用仍不完整）
- 现象：应用 15000/28716、5530/6921，点重新应用后仍不完整。
- 要求：apply 循环处理全部 approved（含批次/进度/失败重试），不因单批错误中断；重新应用能补齐；显示失败条目原因；完成后计数 == 总（除非明确 unknown/rejected）。
- 需排查分批事务、进度上限、异常吞掉、重复跳过逻辑。

### B4 club 本义链被截断
- w-c 卡片/注释面链文本完整显示（可换行、不省略号、不被卡片高度裁切），如「本义③「梅花」→ 牌戏义 → 定为本义「梅花」」。

### B5 注释面「本义」段贴屏幕左端被裁
- 本义区左右增加安全内边距（≥16px），窄屏/字体放大不出现「本」字半截；同样检查注释面其他左侧贴边文本。

## 验收
- 真机 + 浏览器：F1–F5 可用、设置项生效；B1–B5 复现消失。
- 版本 0.3.35；不引入付费 API 调用（AI 仅本地 UI/数据逻辑测试）。

## F6 用户自编辑笔记 / 助记（w 级与 c 级）

- 允许用户为**整个 word（w 级）**或**指定 c（meaning 级）**新增/编辑/删除：
  - 笔记（自由文本，多行）
  - 助记（类型 + 文本；类型沿用 联想/谐音/词根/词源/串记/口诀/其他）
- 入口：
  - 注释面：词级「我的笔记/我的助记」编辑入口；每个 c 行有「编辑」入口（笔记 + 助记）
  - w-c 页：当前 c 的笔记/助记只读展示（若存在），并可从注释面进入编辑
- 数据：用户内容存 Word 本机字段（新增可选字段，不写入内容包；AI 应用不得覆盖）：
  - `userNotes?: Array<{id,text,meaningId?}>`
  - `userMnemonics?: Array<{id,type,text,meaningId?}>`
  - meaningId 缺省 = w 级
- UI 要求：
  - 编辑弹层：目标（单词 / cX 中文）、文本域（自动换行、保存/删除/取消）
  - 保存后注解面/w-c 立即显示，标注「我的」（与 AI/内置区分）
  - 导出/导入迁移包含用户内容；删除后立即消失
  - 不改变学习进度；AI 生成应用不覆盖用户内容
- 测试：data CRUD + export/import + AI apply 不覆盖；UI 新增/编辑/删除/展示；docs/FEATURES + UI-STUDY。

### F6 补充：AI 生成内容也可编辑/删除

- 所有展示的助记（含 AI 生成/内置合并结果）都可「编辑」「删除」。
- 数据方案（不破坏内容包/AI 重应用）：
  - 编辑 AI 助记 → 保存为用户助记副本（`userMnemonics`，目标同一 w/c），并把原 AI 助记的稳定 key 加入 `Word.hiddenMnemonicKeys` 隐藏；
  - 删除 AI 助记 → 仅加入 `hiddenMnemonicKeys`（不改 packItems）；
  - 编辑/删除用户助记 → 直接改/删 `userMnemonics`；
  - 稳定 key = `${meaningId ?? ''}|${type}|${text}`（展示/合并时按 key 去重与过滤）。
- 展示时按 key 去重：hidden 过滤 → 用户副本优先于 AI 原文；用户副本标「我的」，AI 原文标「AI」，均可编辑。
- 重新应用 AI 包/重新生成不恢复被隐藏的 AI 助记（hidden 持久在 Word）。
- 笔记同理：用户可编辑/删除自己的；若将来 AI 生成笔记，也走 hidden/override 机制。

## F7 白板面可配置显示各 c 词组

- 设置 → 白板面：新增开关「白板面显示各 c 词组」（默认关）。
- 开启后，白板面在每个 c 的词性/英文例句下方显示该 c 的**英文词组**（按 phrase.meaningId 过滤；不显示中文翻译，避免泄露答案）；无词组则该 c 不占位。
- 文案/开关与现有「白板面例句数量」「显示音标」并列；设置持久化并导出。
- tests/ui：开关关时不显示、开时显示对应 c 英文词组、无中文翻译。
