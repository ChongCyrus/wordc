## P2-01 错误文案不含 HTTP 状态码（测试连接 + 生成两条路径）

- **简述**：401/402/429 均只显示中文分类文案 + 响应体摘要，不显示 `HTTP 401/402/429`。
- **复现**：
  1. 设置 → AI 扩充 → 填 Key → 测试连接（mock 401/402/429）；
  2. 学习页 → 更多 → AI 补内容 → 有目标时开始生成（mock 401/402/429）。
- **期望（SPEC §1）**：失败显示底层原因（**HTTP 状态 + 响应体摘要**），不得只显示分类文案；SPEC §4 要求生成错误可读、可重试。
- **实际**：
  - 测试连接 401：`连接失败：Key 无效或已过期：请检查 API Key 后重试。（AI 鉴权失败（请检查 Key）：{"error":{"message":"invalid api key"}}）`；402/429 同形，均无状态码。
  - 生成 401：`Key 无效或已过期：请检查 API Key 后重试。`；402：`账户余额不足：请充值后重试。`；429：`请求过于频繁：已自动退避重试，请稍后再试。`（429 自动重试共 4 次请求）。
- **截图**：`docs/assets/qa/ai-0.3.27/S0-01-test-connect-429.png`、`S1-04-error-401.png`、`S1-04-error-402.png`、`S1-04-error-429.png`
- **console**：仅浏览器资源错误 `Failed to load resource: 401/402/429`（预期 mock 响应），无 JS 异常。
- **稳定性**：3/3 状态码稳定复现。

## P2-02 「追加更多」在审核框被标成「（将替换）」

- **简述**：非替换模式（append）生成的条目，审核框标题仍显示「例句（将替换）」/「助记（将替换）」，与保存行为不符。
- **复现**：AI 面板 → 当前词 → 例句 → 生成模式选「追加更多」→ 开始生成 → 审核框；助记 append 同样复现。
- **期望（SPEC §6）**：仅覆盖/替换模式明示「将替换」；追加模式不得提示会替换。
- **实际**：`address · 例句（将替换）`、`address · 助记（将替换）`；实际保存走 `entry.mode='append'`，旧内容未被清空（未造成数据丢失，仅文案误导）。
- **截图**：`S1-05-review.png`、`S1-13-long-text.png`、`S2-06-mnemonic-review.png`
- **console**：无。
- **稳定性**：2/2 类型（例句、助记）稳定复现。

## P2-03 取消生成后的摘要进度与实际草稿不一致

- **简述**：取消后提示「已取消，草稿已保存：已生成 1 / 总 1」，但草稿库中 `done=0`、`cursor=0`、`targetTotal=0`、items 为空；生成中进度当时是 `0 / 1`。
- **复现**：AI 面板 → 助记/追加更多（目标 1）→ 开始生成 → 500ms 内点「取消生成」。
- **期望（SPEC §4/§5）**：取消保留已生成条目并提示「已取消，草稿已保存」；进度数字必须与实际已保存条目一致。
- **实际**：摘要 `已取消，草稿已保存：已生成 1 / 总 1（草稿已保存）`；DB 草稿 `{cursor:0,targetTotal:0,done:0,items:[]}`。取消后草稿确实保留（符合规格），仅计数错误。
- **截图**：`S1-11-running.png`、`S1-12-canceled.png`
- **console**：无。
- **稳定性**：1/1（mock 5s 延迟下复现；真实网络取消时序需复核，建议加单测）。
