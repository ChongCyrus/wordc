# 演示素材（WordC 自产，非官方素材）

全部素材由本项目 Playwright（Chromium）在**公开版 WordC 构建**上录制/截图：
**390×844 逻辑视口、深色主题、默认「2027考研英语大纲词汇」词库、全新 IndexedDB 干净数据**；
不含MaiMemo Token、代理地址、账号/个人信息，也不含官方 App 截图/图标；全片无「受限商业词表」等私版字样。

拍摄数据：公开默认词库中动态选词（演示用 `abdomen`，3 个含义「腹部 / 下腹 / 腹腔」，c1 有词组）；
不熟悉度通过逐次点击含义行产生（1/4/8 次 → 10%/40%/80%）。PNG 以 @2x 输出（780×1688）。

| 文件 | 对应功能 |
|---|---|
| `01-home-kpi.png` | 首页今日任务卡：三 KPI「待复习 / 待新学 / 今日已学」+「复习 a · 新学 b」+「查看今日单词 ›」；当前词库为公开版大纲词库 |
| `02-study-board.png` | 学习白板面：大号英文单词 + 英文例句（无中文释义） |
| `03-annotations.png` | 注释面：**逐个点击 3 个含义标记不熟悉 → 10% / 40% / 80% 三条不同长度与颜色的条形**；三键、记忆按钮、词组 |
| `04-memory-wc.png` | w→c 记忆全屏卡片：`abdomen → 腹部`、计数 **1/3**、当前含义词组 `lower abdomen — 小腹；下腹部` |
| `05-today-words.png` | 今日单词页：复习/新学两分区、「已学评分 / 未学」标签 |
| `06-settings.png` | 设置·学习设置：「每日复习上限」（不限）与「新词顺序」（随机乱序） |
| `07-stats.png` | 统计页：概览、今日反馈与「今日已学 N 个 · 复习 a · 新学 b」 |
| `demo-flow.gif` | **17.0s 循环**（360×779、12.5fps、约 2.0MB，≤8MB）：首页 → 白板 → 注释（**逐个点击 c1×1、c2×4、c3×8 → 10%/40%/80% 三条 bar**，点击 0.35s、末尾停留 1.2s）→ w→c 多含义独立计数（**c1 有词组 1/3→3/3 → c2 1/3→3/3 → c3 1/3→3/3**）→ 三键「认识」 |
