# 本义助记 / 串联助记 Prompt v1.1（task-232，0.3.77）

## v1.1-core-sense-mnemonic

**目的**：为「单词 w → 本义 coreSense」生成 1–2 句中文助记。

**输入**：word、label、可选 gloss(origin)、全部实际含义 c。

**方法优先级（去拉丁化）**：
1. 拆词：熟悉的英文词/字母组合（如 de + nounce 中只取学习者已认识的部件）
2. 谐音 / 中文意象 / 画面 / 生活场景
3. 词组、近义/反义对比、口诀
4. 词源只在「常见记忆锚点」时一句话带过

**禁止/限制**：
- 默认不要用拉丁/希腊/古法语等外语词源；
- 不要让学习者额外记一个外语词源才能记住；
- 不编造词源；不逐条翻译释义。

**输出严格 JSON**：

```json
{ "mnemonic": "1–2 句中文，≤80 字，可含英文拆解" }
```

## v1.1-core-sense-overview

**目的**：把该词全部本义串成一段 60–160 字中文记忆整体。

**输入**：word、全部 coreSenses(index/label/note/origin)、映射 c 摘要。

**要求**：
- 覆盖每一个本义；
- 讲清本义间引申/派生/隐喻关系；
- **优先拆词/谐音/中文意象/场景/词组对比**；默认不用拉丁/希腊/古法语词源；不要求额外背外语词源；
- 不逐条翻译、不编造词源。

**输出严格 JSON**：

```json
{ "text": "60–160 字中文串联助记" }
```
