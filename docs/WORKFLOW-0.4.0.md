## 1. README 建议替换段

替换现有 `**推荐工作流**：...` 一段，改为：

```md
## 工作流：词根词缀法三步

> 核心：先记「词根/词缀/词源 → 核心义」，再把核心义映射到各个实际含义；回忆时反向由含义回到核心义，再推出其它含义。

1. **记忆词根词缀词源**
   在注释面 / 记忆页先看词根、前缀、后缀、词源分解，理解这个词的核心义（生成元）是怎么来的。
2. **加权记忆推导各含义 / 本义**
   用加权记忆把核心义代入各含义的语境、搭配、词性，推导它在此处的实际指代；对推导不出的含义（nc）反复加权巩固。
3. **白板推导 + 针对性巩固**
   白板只看单词/词性/例句，先按词根缀源推导含义；再对不熟含义用加权记忆针对性巩固，直到能仅凭词根缀源想起各含义。

### 映射算法原理

- 词根/词缀/词源不是孤立背诵项，而是**压缩后的核心义**：`词根缀源 → 核心义 / 生成元`。
- 每个实际含义都是核心义在具体语境中的一次**实例化**：`核心义 + 语境 / 搭配 / 词性 / 作用对象 → 实际含义`。
- 记忆时正向建网：先记词根缀源，再逐一推导含义；只对推导失败的含义（nc）加密练习。
- 回忆时反向使用：由已记住的含义反推核心义，再由核心义展开其它含义；核心义遗忘时，用几个已记含义交叉回忆。
- 因此不必为每个含义单独建记忆，只需维护「词根缀源 ↔ 核心义 ↔ 各含义」这张可双向推导的映射网。
```
