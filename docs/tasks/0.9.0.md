# 0.9.0 词根/缀不熟悉度 + 加权映射次数（code144）

## 需求（用户原文要点）

注释面「词根词缀词源」里每个词根/缀（如「前缀 up-」「词根 date」）要能**点击计算不熟悉度**；用线条/温度计形式可视化；加权记忆「只记词根缀」模式下，各映射的**记忆次数按不熟悉度用与含义相同的规则安排**。

## 数据（dev-data）

1. `WordState.partStats?: Record<string, { clicks: number; encounters: number }>`
   - key = `${type}:${normalizeAffixText(text)}`（小写、去连字符）
2. API：
   - `recordPartEncounters(wordId, keys: string[])`：每词每次进入注释面，各 part encounters +1（同一词同一天多次进入各自累计；幂等由调用方控制）
   - `recordPartClick(wordId, key)`：clicks +1
   - `getPartUnfamiliarity(state, key)`：`clicks / max(1, encounters)`，0..1
   - `getPartStats(state)` 读取
3. 加权次数：**必须与含义/本义的加权公式一致**，直接调用 `weightedTotal(base, f, settings)`：
   - base = `memory.totalRepeats`（与其它 w-c 相同）
   - f = 该 part 的 clicks/encounters
   - settings = `memory.weightedMin / weightedMax / weightedK`（与其它类型相同）
   - 不另写公式、不加额外系数或封顶；`partTotals[key] = weightedTotal(...)`
4. 测试：clicks/encounters 比例、clamp、无 stats 为 0、weighted totals 随不熟悉度变化（高→多）、持久化读写。

## UI（dev-ui）

1. **注释面词根缀 chips**：
   - 可点击；点击 = 标记不熟悉（clicks+1），并立刻刷新；
   - 视觉：**chip 本身作为温度计**——chip 背景按不熟悉度从左到右填充（或边框/底色渐变），填充宽度=clicks/encounters；不要额外在下方加线；暗色主题、长词根可换行；
   - 进入注释面时上报 encounters 一次（每个 part）；
   - 提示文案：轻触词根缀可标记不熟悉。
2. **只记词根缀加权**：
   - 每个 part 卡的记忆次数 = partTotals（0.9.0 数据接口）；卡片显示「已记 x / N」；
   - 点击卡片先计数、满 N 后进入下一卡；全部 part 满后进入最后「完整词→组合」卡（计 1 次）或结束；
   - 三小次模式兼容（先显示含义再计数）；
   - 退出/评分/互斥逻辑不变。
3. **可视化**：注释面 chip 即温度计（背景填充）；加权页 part 卡也可用同一填充样式显示该 part 不熟悉度。
4. 测试：点击 chip 调用 recordPartClick/更新条；进入注释面上报 encounters；partTotals 生效（高不熟度 N 更大）；三小次计数；390/360。

## 验收

1. 点「前缀 up-」多次，温度计上升，重启后保留。
2. 进入加权「只记词根缀」：不同 part 的 N 不同（不熟悉度高→N 大）。
3. 卡片计数到 N 才切换；全部完成回注释面/评分。
4. 三小次、互斥、无词源回退、390/360 正常。
