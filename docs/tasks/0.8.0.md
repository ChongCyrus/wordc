# 0.8.0 加权记忆「只记词根缀」模式（code137）

## 需求

在加权记忆的 w-c 页右上角增加「只记词根缀」勾选框，可与既有的「三小次模式」同时勾选。勾选后 w-c 页不再按含义/本义展示，而是展示词根缀映射卡：

1. **词根/缀 → 含义**：键 = 注释面 `rootEtymology.parts[].text`（含类型前缀/词根/后缀/其他），值 = 该 part 的 `meaning`。例：「前缀 pan-」→「全部，所有」。
2. **代表词**：每个词根/缀卡附加 2–3 个含该词根/缀的典型词（基础、常用、易记优先），来源优先词库匹配；无匹配时可 AI 生成。展示词形 + 简短中文义。
3. **完整词 → 组合说明**：最后一张卡键 = 当前词（如 panorama），值 = `rootEtymology.composition`（如「组合：pan-（全部）+ -orama（景象）→全部景象 →全景」）。

- 该模式同样支持「三小次模式」（三击回忆：正面→释义→自评/继续）。
- 词根缀源缺失时：显示「本词暂无词根词缀词源」并回退普通模式（或禁用勾选）。
- 与「只记本义」互斥：勾选只记词根缀时取消只记本义，反之亦然。
- 勾选状态持久化（settings）。

## 数据

- 新增 `memory.rootAffixOnly` 设置（boolean，默认 false）。
- 新增纯函数 `buildRootAffixMappings(word, { deckWords, limit, aiExamples? })`：
  - parts → mapping（type/text/meaning）
  - representatives：按 part 位置匹配词库词（prefix: startsWith；suffix: endsWith；root/other: includes，去重、排除当前词），排序：长度短 → 难度低 → 频率高；取前 3；带 wordId/headword/首义。
  - final：full word → composition（缺 composition 时用 parts 拼接「前缀+词根→义」兜底）
  - 返回 `{ ok, items[], reason? }`，纯函数可测。
- 不做全量 AI 回填；代表词缺省本地匹配，UI 可选「AI 补代表词」按钮（可后续）。

## UI（dev-ui）

- 在 memory-top-stack 的「只记本义」旁增加「只记词根缀」复选框（加权记忆时可见）。
- 勾选后 MemoryStage 替换为 RootAffixStage：
  - 复用既有卡片/三小次/字号/卡片大小/底部评分栏；
  - 卡片：类型标签 + 键 + 值；代表词 chip；
  - 最后一卡完整词 → composition；
  - 退出/切换语义与「只记本义」一致（回到注释面重开，进度重置）。
- 390/360 不溢出；暗色主题；长词根缀可换行。

## 验收

1. 加权记忆勾选「只记词根缀」：w-c 页显示 N 个 part 映射 + 1 个完整词映射。
2. 每个 part 卡有 2–3 个代表词；词库无匹配时留空不报错。
3. 「三小次模式」勾选时：正面→释义→自评流程正常。
4. 与只记本义互斥、状态持久化。
5. 无词根缀词：提示并回退普通模式。
6. tests：buildRootAffixMappings 纯函数、UI 渲染/勾选/互斥；390/360。
