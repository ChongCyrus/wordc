# 0.5.2 任务书：选择前 N + 划分所选批次（code126）

## 背景

高级筛选页当前只有全选/反选/取消全选，没有「选择前 N 个」；也没有把筛选/选择结果按步长划分为多批的能力。用户需要按批处理（AI 生成、临时复习等），并让索引集保存批次。

## 需求

### 1) 选择前 N 个

- 高级筛选结果工具栏增加输入框「选择前 N 个」+ 按钮。
- 按当前排序（sort/direction/groupBy 后的结果顺序）取前 N 个词。
- N 为空/非法/超过结果数时安全处理；N=0 清空选择。
- 选中后底部 N 同步更新。

### 2) 划分所选

- 增加「每批 N 词」输入 + 「划分」按钮。
- 对当前选择（无选择时对当前筛选全部结果）按顺序切分为连续批次。
- 显示批次 chips：「第 1 批 · 50 词」「第 2 批 · 50 词」...，点击某批 = 选中该批词。
- 组内关系不变；批次只是选择的另一种快捷方式。
- 每批大小 1–1000；非法值提示。

### 3) 索引集保存批次

- SavedFilterSet 增加可选 `batchSize?: number` 与 `batches?: string[][]`（按顺序的词 id 数组）。
- 保存索引集时若存在批次，写入 batchSize/batches；wordIds 仍保存完整词快照。
- 载入恢复条件 + 排序/分组 + 快照 + 批次 chips。
- 旧索引集无批次兼容。
- AI 生成页/临时复习选择某批时，使用该批 wordIds。

## 验收

1. 筛选 10 词 → 选择前 3 → 已选 3、AI/临时按钮显示 3。
2. 选择 5 词 → 每批 2 → 批次 chips：2/2/1；点第 2 批选中第 3–4 词。
3. 保存索引集 → 「N 词快照 · M 批」；重进载入后批次恢复。
4. 点批次进入 AI 生成页，来源为该批词数。
5. 390/360 无溢出；旧索引集兼容。

## 4) 临时复习模式恢复（追加）

高级筛选底部「临时复习」必须弹出原设计的选择对话框：

- 加入今日计划（可选含已存在词）
- 立即复习
  - 记录方式：只练不记录（none） / 评分并更新计划（rate） / 评分但不改复习时间（score-only）
  - 自动回炉开关（autoRequeue）

选择后导航 /temp-review，带 words、recordMode、autoRequeue、returnTo（带 restore=1）；完成后回筛选页恢复状态。

验收：筛选2词→临时复习→弹窗三模式可选→none 无评分/不写 DHP；score-only 写评分但不改 due；rate 更新 DHP。
