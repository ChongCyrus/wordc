# 0.6.0 任务书：统一 AI 生成数据页（code127）

## 目标

把分散的 AI 批量生成入口统一到 AdvancedFilter → GeneratePage 一条链，支持全部数据类型、按类型属性组筛选、统一任务/预算/并发/断点续跑。

## 类型（全部）

- 例句 examples
- 词组 phrases
- 助记 mnemonics
- 本义/引申链 semantics
- 本义助记 core-sense mnemonic
- 串联本义/本义 overview
- 含义助记（词义助记）
- 词根缀源 root-etymology
- 引申图 derivation
- 不常考 rare-meanings

## 1. 统一生成页

- GeneratePage 显示来源 N 词（筛选集/批次/任务）。
- 类型多选；每类型配置区。
- 每类型显示：目标数、预计费用、预算、并发（1–8）、每批词数。
- 一个任务可包含多类型；任务持久化 kinds/targets/config/batchSize/concurrency/budget。
- 旧批量面板入口保留，但内部逐步复用同一 runner。

## 2. 按类型属性筛选（属性组）

- 复用 AdvancedFilter 的 groups/conditions（组内 OR、组间 AND/OR）。
- 基础集合 = GeneratePage 来源 wordIds。
- 每类型提供合理属性：
  - 本义助记：是否已标记不常考、是否已有本义助记、含义数
  - 词根缀源：是否有词根数据、是否标记不常考
  - 引申图：是否已有引申图、是否有本义
  - 例句/词组：是否已有、是否标记不常考
  - 不常考：rareStatus、含义数
- 属性筛选结果与基础集合求交；显示最终目标数。
- 不修改任务 targets 快照，只影响本次生成目标。

## 3. 统一任务引擎（全类型）

- GenerationJob：kind(s)、targets、config、batchSize、concurrency、budget、cursor、results/failed、status。
- 所有类型 runner 写同一 job：append result/failed/cursor。
- 支持暂停/继续/重启恢复/取消；APP 重开任务中心可见。
- 任务命名/删除/清理完成。
- 旧 job 无 targets 提示重建。

## 4. 预算/并发/批次

- 并发可配 1–8（默认 2），批次可配（每请求词数/每批目标）。
- 单次预算/全量预算显示；超预算停止并保留进度。
- 生成中可取消，已生成结果保留。

## 5. 验收

1. 筛选 20 词 → GeneratePage 来源 20 → 选 3 类型 → 每类型属性筛选 → 目标数正确。
2. 创建任务 → 关闭/重启 → 任务中心继续 → 只跑剩余，完成状态。
3. 词根缀源/引申图/本义助记/不常考 均在同一个生成页可选。
4. 预算/并发/批次生效；旧入口不崩。
5. 390/360；QA 全绿后发布。
