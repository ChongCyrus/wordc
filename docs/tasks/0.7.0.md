# 0.7.0 词根缀源预装链 + 数据生成（code132）

## 目标

1. 用 CLI + workflow 分片生成商业词表/大纲词根词缀词源数据
2. 生成 `momo-root-etymology-bundle`，放入 APK 预装资产
3. App 启动自动导入预装 bundle（幂等、可断点、手改保护）
4. 不覆盖用户手改/AI 内容；重复启动不重复写

## 数据生成

- `tools/gen-root-etymology.mjs`（已实现）：offset/limit、batch、并发、失败分片、bundle 输出
- 试点：500 词，抽查 parts/meaning/composition、失败率、费用
- 全量：商业词表 5528 词，按 500 分片并行，每片独立输出后合并
- 合并：按 wordId 去重、校验 parts.meaning、统计
- 审计：随机 100 词人工抽查；明显错误词剔除/重生成

## 预装链（dev-data+dev-ui）

- 资产路径：`public/generated/root-etymology.bundle.json`（构建期复制到 dist/APK）
- 启动流程：`ensureDefaultGeneratedData` 增加 rootEtymology：
  - 读 bundle → 校验 format/version/items
  - 只对无 rootEtymology 的词写入（AI 预装）；手改优先
  - meta 记录 `rootEtymology.preinstallVersion/importedAt/count/stale`
  - 已导入且版本相同则跳过；失败不标 completed，下次重试
- MePage「预装内容」显示词根缀源导入数量/版本
- 设置可关闭预装？默认开启。

## 验收

1. 安装包 fresh 启动后自动导入；「预装内容」显示词根缀源 N 条
2. 已手改词不被覆盖；重复启动不重复写
3. 旧版本升级：仅导入缺失词
4. 生成数据失败词有报告，不阻碍启动
5. APK 体积增量可控（bundle gzip/精简）
6. QA fresh + 升级 + 恢复回归
