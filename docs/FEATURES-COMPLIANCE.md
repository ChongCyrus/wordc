## 明确「没有做」的事

- 未复制官方客户端代码、未使用官方前端代码片段、未使用官方图标/截图/商标；
- 未内置受限商业词表；
- 未提供托管代理、未收集/上传用户 Token 或学习数据；
- 未声称与官方数值逐词一致（调度/进度均为近似）。

## 证据等级说明

- **A**：官方前端/客户端**公开可观察行为**（本机实测复核，例如三键三态、标签切换）；
- **B**：官方帮助文档/公开 API 文档/官方公开数据说明；
- **C**：官方或社区公开数据集（难度、词表、词组）；
- **D**：本项目推断/拟合（如五档状态机未观测边界、首评参数拟合、词组归属算法）。
